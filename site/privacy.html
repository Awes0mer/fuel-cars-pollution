Privacy

Short version: this site collects nothing about you.

  • No tracking. No cookies, analytics, advertising, fingerprinting, forms or accounts. The pages load nothing from any other website; the project’s test suite checks every page for this.
  • The calculator stays in your browser. The sliders and buttons run locally; nothing you choose is sent anywhere.
  • Hosting. The files are served by Netlify. Like any web host, Netlify may record technical request data such as IP address, browser type and time of request in its server logs, under Netlify's privacy policy. This project does not receive or use those logs.
  • While the site is private, Netlify's own sign-in page controls access for the project team. That page is Netlify's, under its policy.
  • Data on the site. Only public statistics from government and open-data publishers. No personal or business data.
  • Questions. Open an issue on the project repository once it is public.
