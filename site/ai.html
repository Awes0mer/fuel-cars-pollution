AI disclosure

  • Who built it. The code, analysis, page design and text were produced by an AI coding assistant, Claude Opus 5.5 running in Claude Code (Anthropic), working under the direction of the project author. The author set the brief and the rules, and approved each outward step such as hosting and publishing.
  • No AI at runtime. No AI model runs on this site or inside the learning loop. The learning is recursive least squares; its link strengths are stored in HydraDB.
  • No hand-typed numbers. Every figure on the site is generated by code from the downloaded files and the result files in the repository; tests check that the pages match those files.
  • Rule first. The pass/fail rule was written and committed before the first run and was not changed after the result was known.
  • Walkthrough video. The narration is Omer’s own recorded voice, not a generated voice. Editing the video and aligning the captions were assisted by ChatGPT (OpenAI) and by Whisper speech-to-text run locally.
  • Mistakes are possible. AI-written code and text can be wrong. The tests, the data check and the open repository are there so anyone can verify the work.
